# CCHH Mobile · 免费社区测试版使用与验收

**当前状态：开发中，仅供授权隔离测试；未达到群发验收条件。** CCHH Mobile 是基于 cc-haha 的非官方 Android 原生客户端。每个人在自己的手机安装同一 APK，使用自己电脑上的 CCHH 0.7.4。客户端不提供集中账号或开发者代理，不要求使用作者的账号、网络、密钥或服务器。

## 免费连接：每位群友使用自己的环境

| 方式 | 准备 | 手机上的做法 | 注意 |
| --- | --- | --- | --- |
| 同一 Wi-Fi | 电脑开启 CCHH「设置 → H5 访问」，手机与电脑同网 | 选择「同一 Wi-Fi」→ 扫描电脑的 H5 二维码 → 确认地址 → 连接 | 只在可信私有网络使用 H5 令牌 |
| Tailscale（个人免费方案，在其适用条款及限额内） | 电脑、手机分别安装并加入使用者**自己的** Tailscale 网络 | 选择「Tailscale」→ 扫描 H5 二维码获取令牌 → 把连接地址核对/调整为**同一台电脑**的 Tailscale IP → 连接 | H5 二维码可能给局域网 IP；Tailscale 是单独安装的网络工具，不能把普通 LAN 地址当成远程地址 |
| ngrok 公网（免费限额，实验性） | 用户自己注册符合条件的免费 ngrok 账户，在自己的电脑 CCHH 公网设置开启 | 选择「公网 ngrok」→ 扫描 **/remote#pair=** 形式的公网二维码 → 电脑端批准配对 → 手机上检查审批 | 必须 HTTPS；不可拿 H5 私有令牌当公网配对码。受 ngrok 免费流量/请求限制，第三方隧道可处理传输内容 |

不需要付费服务器、购买域名、开发者代付或使用开发者个人连接。**免费服务的政策、速率和配额可能变化，网络环境也可能不支持某些方法。** 不保证任何一个公网服务永远免费或持续在线。CCHH 使用的 AI 模型/API 是否收费，取决于用户自己的供应商。

## 安装和连接

1. 在自己的 Windows 电脑上确认 CCHH 0.7.4 正常运行，设置中开启对应访问方式；电脑必须保持开机。
2. 安卓手机安装社区 APK 后，打开「连接我自己的 CCHH」。点击首次连接指引。
3. 选择连接方式，**只扫描自己电脑生成的二维码**。不要将带 H5 令牌或公网配对密钥的截图、链接发送到任何群聊。
4. 局域网/Tailscale：检查 QR 自动读取的地址与自己的电脑一致，点击连接；公网：在电脑上批准自己的手机，点击检查审批。
5. 进入自己的会话列表。开始任务前先核对会话和目标电脑，所有命令均在配对的那台电脑执行。

扫码仅填充待确认的地址和令牌，**不会自动发送聊天消息**。切换连接模式时清除尚未提交的旧连接凭据和待批准请求。解除配对会清除手机储存的连接配置，但需要电脑端撤销相关公网设备授权才算完全撤销；不要将手机交给不可信的人使用。

## 群友反馈前的验收清单（不得跳过）

- [ ] 使用同一 APK，在至少两部真实 Android 手机、两台不同电脑、不同账号之间独立配对；绝无共享会话/令牌。
- [ ] LAN、Tailscale 的单独网络与 ngrok 公网配对（如果提供）分别完成人工全流程；无开通收费功能。
- [ ] 网络断线、Wi-Fi 切换蜂窝网络、锁屏唤醒、电脑休眠/恢复，均不重复发出用户任务。
- [ ] 权限批准/拒绝/撤销、流式文字输出及同一会话历史一致性验收。
- [ ] 二维码恶意链接、错配电脑地址、过期/已撤销授权均拒绝；日志和构建产物不包含个人密钥。
- [ ] 安装、重装和升级真实设备验证；明确支持的最低 Android 系统版本与权限。
- [ ] APK 发布版本用**长期一致的受保护签名**，并提供 SHA-256。当前 CI 临时签名并不保证升级兼容。
- [ ] 检查 CCHH v0.7.4 源码许可证、第三方声明、完整非商业分发要求、版权/来源署名；APP 显示 About/法律页面并与 APK 一起附完整声明。
