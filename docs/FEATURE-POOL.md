# CCHH 功能候选池

## 1. 升级补丁安全网（优先级高）
- 痛点：11-04 漏记台账；Token 单位/插件计数/repatch 等补丁老被升级覆盖
- 方案：升级前自动快照 + 补丁登记；升级后自动 diff + 自动重放 + 白屏检测 + 一键回滚
- 现成雏形：`patch-replay-ledger` skill、DEPLOY-LOG 台账、verify-replay.ps1、一堆 swap-*.ps1
- 状态：待做

## 2. 后台任务完成收件箱（优先级高）
- 痛点：用户原话「天天盯屏幕已经累了」；agent/定时任务干完没有集中收件箱
- 方案：后台任务完成统一收件箱 + 手机推一条（已有 mobilePush.ts / Telegram 桥可复用）
- 状态：待做

## 3. 会话回收站（优先级中）
- 痛点：会话只有硬删除（batch-delete），手滑删错没法恢复；会话里可能有值钱的产出
- 方案：删除先进 trash 目录保留 N 天，UI 加「已删除」列表可恢复
- 改动点：sessions.ts batch-delete 路径 + Sidebar 过滤 + 恢复按钮
- 状态：待做

## 4. 会话收藏/置顶（优先级中）
- 痛点：重要会话混在长列表里，只有项目 pin 没有会话 pin
- 方案：session summary 加 pinned 标记，列表置顶 + 收藏过滤
- 状态：待做

## 5. 全局命令面板 Ctrl+K（优先级低）
- 痛点：切模型/开会话/跳设置要鼠标点好几层
- 方案：全局快捷键呼出面板，聚合「切模型/开会话/搜会话/跳设置」
- 状态：待做

## 已否掉
- provider fallback 链 / 预算告警 / 跨会话用量面板 / 提示词库（用户：没用）
- Arena 同题 A/B、自动 lint/test（用户：没用）
